# Project Summary

This project was built after completing LPIC-1 training.  
It demonstrates practical Linux system administration skills including:

- Linux installation
- Disk partitioning
- LVM management
- Filesystem mounting
- User and group management
- ACL permission control
- SSH hardening
- Sudo configuration
- Networking with nmcli
- Package management with dnf
- Bash scripting
- Systemd service and timer
- Log analysis with GNU/Linux commands
